# AcademiaFlow

Sistema de organização de atividades e lembretes acadêmicos (POO com TypeScript).

## Requisitos
- Node.js 22 ou superior

## Como executar
npm install
npm start


## Estrutura
- src/dominio: classes e regras de negócio (sem acesso à tela)
- src/visao: interface, eventos e persistência em localStorage
- public/dados-iniciais.json: dados de demonstração
- docs/: diagrama de classes UML
